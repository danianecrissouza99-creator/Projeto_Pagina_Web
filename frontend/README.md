# MEDCEI - Gestão de Saúde ao Domicílio & Simulador SIR 🏥

Este é o projeto MEDCEI, uma plataforma de gestão de utilizadores com um simulador epidemiológico SIR (Suscetíveis, Infetados, Recuperados) integrado, desenvolvido em React.

## 🛠️ Pré-requisitos
Para correres este projeto no teu PC, vais precisar de ter instalado:
1. **[Node.js](https://nodejs.org/)** (Para rodar o frontend React/Vite)
2. **SQL Server** (Para a base de dados)
3. **Python / Node** (Dependendo do que estiver configurado para o Backend na porta 3001)
